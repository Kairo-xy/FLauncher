# Verya Launcher

A minimal Android home screen launcher built with Kotlin and Jetpack Compose.

## Features
- Acts as a real Android home app (pick it as your default launcher)
- Home screen with live clock and dock
- Swipe up for the app drawer with search
- Tap to launch, long-press for app info

## Build
Every push builds a debug APK via GitHub Actions. Open the **Actions** tab, pick the latest run, and download the `verya-launcher-debug` artifact.

To build locally: open in Android Studio and run the `app` module.
